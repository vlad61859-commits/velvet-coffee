# Velvet Coffee ☕

Velvet Coffee is a modern and responsive coffee shop website created as a frontend portfolio project.

The goal was to build a visually attractive website with a premium atmosphere, smooth interactions and a responsive layout that works well on desktop, tablet and mobile devices.

## Live Demo

[View website](https://vlad61859-commits.github.io/velvet-coffee/)

## Technologies

* HTML5
* CSS3
* JavaScript
* Responsive Design
* CSS Grid
* Flexbox
* Intersection Observer API

## Features

* Responsive navigation
* Mobile menu
* Hero section
* About section
* Coffee menu
* Interactive gallery
* Gallery lightbox
* Customer reviews slider
* Contact form
* Scroll animations
* Smooth scrolling
* Hover and micro animations
* Responsive design for desktop, tablet and mobile

## Design

The website uses a dark premium visual style with warm gold accents.

The design was created around the atmosphere of a modern coffee shop, using large photography, elegant typography and subtle animations.
